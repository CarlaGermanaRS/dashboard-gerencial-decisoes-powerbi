# 📊 Dashboard Gerencial para Tomada de Decisões com Power BI

## 📌 Descrição do Projeto
Este projeto consiste na refatoração e otimização visual (UX/UI) de um relatório gerencial de vendas e lucros desenvolvido no Power BI, como parte do desafio prático da plataforma **DIO (Digital Innovation One)**.

O objetivo principal foi aprimorar a usabilidade, interatividade e clareza visual dos dados para suporte à tomada de decisões estratégicas.

---

## 🚀 Melhorias e Funcionalidades Implementadas

- **Visual Temporal:** Conversão do gráfico de linhas para **Gráfico de Área**, facilitando a visualização do volume e tendência dos lucros ao longo do tempo.
- **Análise Cruzada (Matriz):** Criação de uma **Matriz de Descrição de Vendas** detalhada, organizando os dados por **Segmento** e **Produto**, permitindo analisar as métricas de *Vendas*, *Lucros* e *Unidades Vendidas*.
- **Navegação Dinâmica:** Adição de **Botões de Navegação de Páginas** no topo do relatório para alternar facilmente entre as páginas de **Vendas** e **Lucro**.
- **Layout & Estilização:** Ajustes de alinhamento, espaçamento e hierarquia visual para uma melhor experiência do usuário (UX/UI).

---

## 🛠️ Tecnologias Utilizadas

- **Power BI Desktop**
- **DAX (Data Analysis Expressions)**
- **Dataset Financials** (Amostra de Vendas)
